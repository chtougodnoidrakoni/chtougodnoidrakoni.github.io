# Лист персонажа — клуб «Что угодно и драконы»

Конструктор листа персонажа D&D: страницы A4 из блоков, которые можно двигать, растягивать, переименовывать, менять им шрифт и рамку. Добавляются свои страницы и блоки. Заклинания выбираются из базы SRD, и их полные описания сами собираются в «книгу заклинаний». Можно добавить свои заклинания.

Приложение: https://zamirsarsenov9393-ux.github.io/chd-sheet/

- **Заполнение** — вписываете текст, отмечаете навыки, закрашиваете ячейки и спасброски.
- **Макет** — двигаете блоки пальцем, размер меняется за кружок в углу; подпись, шрифт, рамка, точные размеры — в панели снизу.
- **PDF** — печать из браузера, A4, поля 12 мм белые (принтер не печатает края).
- Листы хранятся на устройстве, сохраняются файлом `.json` и открываются обратно.

Описания заклинаний — System Reference Document 5.1 и 5.2 (Wizards of the Coast, CC-BY-4.0). Неофициальный проект.

```
npm ci && npm run dev     # разработка
npm run build             # сборка PWA
npm run e2e               # браузерный тест
```
